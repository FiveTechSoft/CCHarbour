✻ CCHarbour Playground v0.8.8 A browser playground for the CCHarbour coding assistant — Claude Code-style, multi-platform (Windows, macOS, Linux), ~2 MB native binary. Documentation · Download the native binary Browser tools: file / web / github / memory / todo_write. Shell, subagents, plan-mode, lean-mode and the box UI ship in the native binary.

Settings

Keys are stored in this browser's localStorage and are sent only to the official DeepSeek and GitHub APIs. Web search uses DuckDuckGo (no API key needed). This is a client-side playground — do not use it on a shared or untrusted computer.
