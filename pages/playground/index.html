Browser tools: file / web / github / memory / todo_write. Shell, subagents (incl. background), plan-mode, lean-mode and the dynamic box ship in the native binary.

Settings

Keys live in this browser's localStorage and are sent only to the selected provider and to GitHub. Web search uses the DuckDuckGo Instant Answer API (no key). Each provider gets its own key slot, so you can keep several configured at once. Do not use a shared computer.
