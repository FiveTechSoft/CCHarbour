## Quick test now (Windows)

If you prefer local testing on Windows:

1. Download `cc.exe` from the [latest release](https://github.com/FiveTechSoft/CCHarbour/releases/latest)
2. Set your API key:

   ```bat
   set DEEPSEEK_API_KEY=sk-...
   ```
3. Run:

   ```bat
   cc.exe
   ```
